# Model and asset license register

Every model, dataset, firmware blob, font, icon, image, code package, and generated asset shipped with Fabric OS must be recorded before release.

Required fields:

- Asset name and exact version/hash.
- Source URL or supplier and date obtained.
- Copyright holder and license identifier.
- Redistribution, modification, attribution, notice, and commercial-use conditions.
- Security/provenance review and whether the asset can phone home.
- Where it is shipped and how it can be removed or updated.
- Responsible reviewer and approval date.

Do not ship a model or asset because it is easy to download. If the terms are unclear, keep it out of the release until reviewed.
