# Personal-data incident response

1. **Detect and contain**: preserve evidence, limit access, rotate credentials if needed, and stop ongoing exfiltration.
2. **Record**: capture when the incident was detected, systems/data affected, people involved, and containment actions.
3. **Assess**: determine whether personal data was involved, the categories and approximate volume, likely impact, and whether the event is reportable.
4. **Notify**: escalate to the approved privacy contact and supervisory authority/affected people when the applicable law requires it. For GDPR controller breaches, use the documented path to assess the 72-hour authority deadline.
5. **Recover**: remediate, restore safely, invalidate compromised access, and verify monitoring.
6. **Learn**: document root cause, corrective actions, owner, due date, and whether policies or the DPIA need updating.

Do not put API keys, passwords, full personal-data exports, or sensitive model content into tickets, logs, or public issue trackers.
