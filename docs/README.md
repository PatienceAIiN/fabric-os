# Fabric OS documentation

This index separates public product language from internal engineering records. The website uses the public principles and launch status only; detailed implementation, threat records, and business rules remain in the repository.

## Product and architecture

- `../ARCHITECTURE.md` — system principles and current component map.
- `../ROADMAP.md` — milestone state and future work.
- `STATUS.md` — honest implemented, partial, and deferred status.
- `design/` — product and interface decisions.
- `research/` — research and ecosystem notes.
- `decisions/` — architecture decision records; each records problem, alternatives, decision, trade-offs, security, performance, and migration path.

## Security and trust

- `../SECURITY.md` — security posture, reporting, credential rules, and threat boundaries.
- `threat-model/` — threat records and tests.
- `compliance/INCIDENT-RESPONSE.md` — personal-data incident workflow.

## Privacy, licenses, and release

- `compliance/OS-DATA-GOVERNANCE.md` — OS-wide data classes and control requirements.
- `compliance/GDPR-READINESS.md` — GDPR control map.
- `compliance/OS-LAUNCH-READINESS.md` — website + OS launch blockers.
- `compliance/MODEL-AND-ASSET-LICENSES.md` — license/provenance register for models and assets.
- `release/RELEASE-CHECKLIST.md` — source, supply-chain, OS, recovery, and public-release gates.
- `release/DEVICE-VALIDATION.md` — real-device install, hardware, recovery, and support evidence.

Nothing in this index is a legal certification. Each release needs named owners, evidence, dates, and approval.
